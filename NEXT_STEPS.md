## Enable GitHub Pages

1. Go to your repository: https://github.com/merek452/npc-mindmap-viewer
2. Click **"Settings"** (top menu)
3. Scroll down to **"Pages"** in the left sidebar
4. Under **"Source"**, select:
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Click **"Save"**

## Your Site Will Be Available At

After 5-10 minutes, your site will be live at:
```
https://merek452.github.io/npc-mindmap-viewer/
```

## Troubleshooting

**Site not loading?**
- Wait 5-10 minutes after enabling Pages
- Check that repository is Public (or you have GitHub Pro)
- Verify branch and folder settings

**Images not loading?**
- Images are in `../../Images/` relative to the HTML
- For GitHub Pages, you may need to adjust paths
- Consider moving images to a folder in the repository

**Need help?**
- Check `GITHUB_PAGES_SETUP.md` for detailed instructions
- GitHub Pages documentation: https://docs.github.com/en/pages
